# Code of Conduct

We want MusicContext to be a project where people can disagree about technical details without it getting personal.

**Expected:** be respectful, assume good faith, give specific and kind feedback, and accept it the same way.

**Not acceptable:** harassment, insults, discriminatory language or jokes, personal attacks, doxxing, or sustained
disruption of discussions.

Maintainers may edit, hide or remove comments, issues and pull requests that break these rules, and may block
people who do so repeatedly.

To report a problem, use GitHub's "Report content" on the offending comment, or open a private security advisory
on the repository if the matter is sensitive. Reports are handled confidentially.

This policy is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
